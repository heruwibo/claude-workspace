# Consulting deck style skills

One skill per consulting-firm slide style. Each folder holds a `SKILL.md`.

| Skill | Signature traits |
|---|---|
| mckinsey-style-deck | Answer-first, action titles, MECE, navy/blue |
| bcg-style-deck | Insight headlines, frameworks, takeaway boxes, green |
| bain-style-deck | Results-first, quantified impact, bridges, red accent |
| deloitte-style-deck | Methodical structure, RAG/maturity, roadmaps, green accent |
| accenture-style-deck | Transformation narrative, architecture and journeys, purple |
| kpmg-style-deck | Risk and controls oriented, evidence-based findings, deep blue |
| pwc-style-deck | Practical outcomes, stat callouts, key-takeaway boxes, orange/coral |

Styles are emulated from general public conventions; no logos or trademarks are included. Colors are approximate.

To make them available to Claude Code, copy or symlink the folders into `~/.claude/skills/` (or a project's `.claude/skills/`).
